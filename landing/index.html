What it sets up

Each app does one small job. The setup installs the ones you pick and connects them.

  • JellyfinWatch movies, shows, anime and live TV on any device
  • SeerrA page where family and friends ask for something to watch
  • SonarrFinds and downloads TV shows and anime
  • RadarrFinds and downloads movies
  • ProwlarrKeeps the list of search sites, and tests them
  • qBittorrentDoes the downloading, and stops uploading when it is done
  • BazarrFinds subtitles, English first
  • FlareSolverrGets searches past robot checks
  • KapowarrFinds and downloads comics
  • KaizokuFollows manga and downloads new chapters
  • HomepageOne page with a button for every app
  • TailscaleOptional. Safe HTTPS addresses that work from anywhere

How it goes

  1. Run the line.It checks Docker, downloads the setup, and prints a web address.
  2. Answer a few questions.In your browser. What you watch, where files live, which apps to add. About 5 minutes.
  3. It does the rest.Installs, links every app, then runs a real search to prove it works. 5 to 15 minutes.

Stopping is always safe, and your media is never touched. Works on a Proxmox LXC and any computer with Docker.
