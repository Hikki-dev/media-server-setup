# Security

## Reporting a problem

Please do not open a public issue for a security problem. Use the Report a vulnerability button on the Security tab of this project on GitHub. Say what you found and how to repeat it. We will reply as soon as we can.

## What this project protects

1. Passwords you choose are kept in a private file on your own computer, readable only by you. They are not written to logs.
2. The setup page only listens on your own computer unless you change that.
3. Downloads cannot run programs. Program files are blocked, and nothing runs when a download finishes.
4. Your own apps are only read until you approve each change.

## What to keep in mind

1. Anyone who can open the setup page on your network can change your setup. Do not open its port to the internet.
2. NordVPN service logins and notification links are secrets. Keep them out of screenshots and bug reports.
